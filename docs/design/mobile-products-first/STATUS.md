# Produkter først på mobil – 10. oktober 2026

Implementert, ikke publisert. Avventer godkjenning av forhåndsvisning.

Mobil opptil 600 px: produktlisten med filtre ligger rett etter eksisterende toppfelt på merke- og seriesider, foran Produktserier / Finn din variant og prisinnsikt. Desktop beholder tidligere rekkefølge. Toppfeltet er uendret.

Kun CSS-rekkefølge og omsluttende div-elementer. Alle 83 merke-/seriesider har identisk tekst, lenker, metadata og scripts, inkludert schema, mot forrige bygg. Visuell kontroll ved 375 og rekkefølgekontroll ved 1024 px på Acuvue og Acuvue Moist. Ingen kortoverflyt. Ingen dupliserte produktlister.
