# Desktopkort – utkast 10. oktober 2026

Ikke publisert. Desktop over 600 px får eksisterende sparemerke, overstrøket høyeste gyldige butikkpris og Fra-pris, enklere blå knapp og hvitt bildefelt med større bilder. Produktnavn og linsetype beholdes, ekstra spesifikasjoner og merke-/produsentlinje skjules som på mobil. Ekvivalent-produktlenker for egne merkenavn beholdes.

Kun CSS. Mobilreglene, priser, lenker, schema og spareberegning er uendret. Eksisterende private-label-unntak for sparemerke beholdes. Ingen bildefiler er endret; noen kildebilder fremstår uklare ved større visning.

Kategori og Acuvue kontrollert ved 375, 1024 og 1440 px. Forhåndsvisning med lokale bildekopier og blokkert tredjepartsskript/font. Venter på tilbakemelding.
