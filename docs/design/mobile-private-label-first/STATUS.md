# Egne merkenavn på mobil – 10. oktober 2026

Implementert og kontrollert; ikke publisert.

Samme produkter-først-regel som ordinære merker og serier, etter eksisterende toppfelt. Egenlaget topplogo skjules på mobil opptil 600 px. Felles mal dekker iWear, EyeQ, easyvision, Ascend og trueLens. Desktop beholder logo og tidligere rekkefølge. Produktillustrasjoner og produktkort er uendret.

Alle fem sider kontrollert ved 375 og 1024 px: riktig rekkefølge og logosynlighet, ingen kortoverflyt. Innhold, lenker og schema beholdes i statisk HTML.
